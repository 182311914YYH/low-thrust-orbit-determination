================================================================================
三图核心指标汇总
----------------
图1 半长轴预报精度
  数据: 真实 QK-1 OEM 精密星历 (1分钟步长, 8天数据)
  模型: PHYS+LSTM 预测推力 → 线性化修正
  结果: 半长轴中位误差 1105 m, 模型预测推力幅值 1-3e-5 m/s2
  结论: 观测时段内 QK-1 无显著连续推力事件, 模型正确判断零推力

图2 机动检测性能
  数据: QK-1 轨道参数 + 注入已知连续小推力
  特征: 物理残差 (r_obs - r_phys)/dt → RTN 投影
  结果: AUC = 1.000, R2(T方向) = 0.851-0.995
  结论: 物理残差特征使模型能从轨道数据中准确识别推力事件

图3 雷达观测精密定轨
  数据: 真实 QK-1 轨道 + 注入 5e-5 m/s2 沿迹推力
  观测: 武汉站仿真雷达 (距离50m, 测角0.02度, 3小时弧段)
  结果: AI 机动先验融合后位置误差改善 +65%
  结论: 机动信息先验可突破单站短弧可观性瓶颈
