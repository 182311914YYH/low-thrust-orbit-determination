================================================================================
  非合作航天器连续小推力精密定轨与智能预报
  PINN+LSTM 模型 — 项目成果
================================================================================

项目目标
--------
针对非合作航天器（目标星轨道数据已知但推力参数未知），构建物理+
AI 混合模型，从轨道观测中检测并估计未知连续小推力，融合机动信息
提升精密定轨与轨道预报精度。


物理模型
--------
高精度轨道力模型 (物理力模型/):
  - 中心引力 + EGM96 球谐引力场 (degree 20)
  - NRLMSISE-00 大气模型 (NASA 官方 Fortran 封装, F10.7+Ap 驱动)
  - 太阳光压 (圆柱/圆锥阴影模型)
  - 日月三体引力摄动 (astropy, 带缓存优化)
  - DOP853 自适应积分 + 固定步长 RK4 传播器
  - 12 小时预报基线: 物理噪声 ~1.5 km

航天器参数: 质量 168 kg, 阻力系数 Cd=2.2, 面质比 0.024 m2/kg,
           26 mN 霍尔推力器 (公开报道)


AI 模型
--------
PINN+LSTM 双头架构 (AI融合模型/):
  - LSTM 编码器: 2 层 × 64 维, 输入 144 步历史
  - 回归头: 预测三轴 Δa_RTN 推力矢量
  - 分类头: 机动/无机动二值检测
  - 核心特征: 物理残差 dr_RTN = (r_obs - r_phys) / dt
  - 训练: degree-2 自洽仿真 (数据生成器=物理模型, 残差纯净)

关键验证结果:
  - 仿真数据 (物理残差特征):   T 方向 R2 = 0.995
  - STK HPOP 真实轨道验证:     AUC = 0.998, T 方向 R2 = 0.884
  - 真实 QK-1 (524 天无机动):  模型正确输出 Δa ≈ 0


三图核心指标
------------
图1  半长轴预报精度
  数据:  真实 QK-1 OEM + 高精度物理传播 (NRLMSISE-00+EGM20+SRP+III)
  结果:  SMA 中位误差 ~1.5 km (12 小时预报)
  结论:  QK-1 观测时段内无连续推力, 1.5 km 为当前物理模型预报上限

图2  机动检测性能 (仿真验证)
  数据:  QK-1 轨道参数 + 注入已知推力 + 物理残差特征
  结果:  AUC = 1.000, R2_T = 0.995, 零误报零漏检
  结论:  物理残差特征使模型能从轨道数据中准确提取推力信号

图3  雷达观测精密定轨与机动融合
  数据:  真实 QK-1 轨道 + 武汉站仿真雷达 + AI 机动先验
  结果:  AI 机动融合后定轨位置误差改善
  结论:  机动信息先验可提升单站短弧定轨精度

入口: python run.py


主要限制与后续工作
------------------
1. 真实 QK-1 在 524 天观测期内无连续小推力事件
   → AI 模型在仿真 + STK 数据上完成验证, 缺乏真实机动场景测试
2. 物理模型噪声 ~1.5 km (12h) 仍未达到 <100 m 目标
   → 瓶颈在大气密度的时变波动, 需要 GPS 级跟踪或更长的 OD 弧段
3. 高精度物理模型仅在推理端使用
   → AI 训练使用 degree-2 自洽仿真, 未尝试端到端高精度训练
