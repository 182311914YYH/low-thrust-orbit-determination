# low-thrust-orbit-determination
# 非合作航天器连续小推力精密定轨与预报

## 项目简介

本项目为企业项目式实习项目，研究对象为存在连续小推力机动的非合作航天器。

针对连续小推力作用下轨道缓慢变化、机动参数未知以及轨道长期预报精度下降等问题，建立一套完整的软件系统，实现：

- 连续小推力轨道动力学建模
- 单站雷达观测仿真
- 精密轨道确定（Orbit Determination）
- 连续小推力参数估计
- 轨道长期预报
- 定轨与预报误差分析

整个项目采用 MATLAB 进行开发，并按照模块化的软件工程方式组织代码，为后续算法扩展（如机器学习、Informer、GNN等）预留统一接口。

## 软件开发规范

- 所有公共参数统一保存在 `default_config.m`
- 各模块不得重复定义公共常数
- 各模块通过统一接口进行数据交换
- 新增功能不得修改其他模块接口
- 所有程序均采用 MATLAB 编写
