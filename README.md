# low-thrust-orbit-determination

# 非合作航天器连续小推力精密定轨与智能预报

## 项目简介

本项目面向存在连续小推力、弱机动和轨道缓慢漂移特征的非合作低轨航天器，研究如何在推力信息未知、观测弧段有限、动力学模型存在误差的条件下，实现轨道状态估计、机动识别和中长期轨道预报。

传统轨道预报主要依赖确定性动力学模型。当航天器存在低量级、长时间持续的推进作用时，推力产生的轨道变化在短时间内并不明显，但误差会随传播时间不断积累，尤其容易在沿迹方向形成较大的预报偏差。同时，单站雷达短弧观测存在可观性不足，仅依靠传统定轨方法难以稳定分离初始状态误差、环境摄动误差与未知推力影响。

针对上述问题，本项目构建了一套"高精度物理传播—轨道残差提取—PINN+LSTM推力识别—轨道动力学修正—雷达精密定轨融合"的完整技术体系。系统不直接使用神经网络预测航天器绝对位置，而是利用神经网络从历史轨道序列中估计RTN坐标系下随时间变化的等效推力或残差加速度，再将该加速度重新引入轨道动力学方程进行传播，从而兼顾轨道运动的物理连续性、结果可解释性和未知机动建模能力。

---

## 研究目标

项目围绕非合作航天器连续小推力条件下的轨道确定与预报问题，实现以下目标：

- 建立包含主要空间环境摄动的高精度轨道动力学模型；
- 实现ECI、ECEF、ENU和RTN等坐标系以及UTC、JD和GMST等时间系统转换；
- 构建单站雷达距离、方位角和俯仰角观测仿真与精密定轨流程；
- 从历史轨道序列中提取物理传播残差和机动特征；
- 使用PINN+LSTM模型估计时变RTN三轴等效推力；
- 将预测推力与物理传播器融合，获得满足动力学约束的轨道预报结果；
- 在真实精密星历、注入连续小推力场景、STK高精度传播器验证和仿真雷达观测场景下进行综合验证；
- 对轨道预报精度、机动检测能力和定轨改善效果进行定量评价。

## 高精度轨道动力学模型

项目使用统一的ECI六维状态描述航天器运动，并在物理传播器中组合以下加速度模型：

- 地球中心引力；
- J2摄动；
- EGM96高阶球谐重力场，最高支持20阶20次；
- NRLMSISE-00大气密度模型（NASA官方Fortran封装，F10.7太阳射电流量及Ap地磁指数驱动），可降级为指数阻力模型；
- 带圆柱或圆锥阴影判断的太阳光压；
- 太阳和月球三体引力摄动；
- RTN坐标系三轴经验加速度或连续小推力；
- 可估计的大气阻力缩放系数。

数值传播部分支持DOP853、RK45等自适应积分方法，并提供固定步长RK4快速传播接口。高阶球谐引力采用归一化缔合勒让德函数递推计算，以降低20阶重力场在大批量轨道传播中的计算开销。天体位置（太阳、月球）按小时缓存复用，避免每次右函数调用中重复计算。

物理模型可分别配置为"真值模型"和"估计模型"，便于开展摄动力开关、模型失配、参数偏差和不同精度等级下的对比实验。

## PINN+LSTM连续小推力模型

### 历史序列编码

模型使用两层LSTM对航天器历史轨道及相关物理特征进行编码。默认输入为144个历史时间步，每个时间步包含位置、速度、轨道参数或物理残差等组合特征。两层LSTM的末端隐藏状态拼接后形成航天器当前动力学状态和潜在机动模式的紧凑表示。

目前模型在训练阶段使用degree-2（J2 only）自洽仿真数据，以保证物理残差特征的纯净性（数据生成器与特征提取器使用相同物理模型）。在推理阶段，轨道传播使用完整的高精度NRLMSISE-00+EGM20+SRP+III力模型，AI修正通过线性化状态修正叠加在高精度物理基线上。

### 神经推力函数

LSTM隐藏状态与未来查询时刻的多尺度正弦、余弦时间编码共同输入多层感知机，输出连续时间上的RTN三轴等效加速度：

```text
Δa_RTN(t) = [Δa_R(t), Δa_T(t), Δa_N(t)]
```

其中：

- `Δa_R` 表示径向等效加速度；
- `Δa_T` 表示沿迹等效加速度；
- `Δa_N` 表示法向等效加速度。

模型输出通过平滑有界映射限制在合理推力量级内，避免出现不符合低推力航天器特征的异常加速度。

### 物理融合传播

预测得到的RTN加速度通过RTN到ECI方向余弦矩阵转换至惯性坐标系，并与已知物理加速度叠加：

```text
a_total = a_physics + C_RTN_to_ECI · Δa_RTN
```

系统提供两种融合传播方式：

1. **可微分RK4传播**：将神经推力直接嵌入轨道微分方程，适合端到端物理约束训练；
2. **线性化状态修正**：在预计算物理轨道基础上递推位置和速度修正量，适合大规模训练和快速推理。

该设计使模型学习目标由"直接拟合未来位置"转变为"估计物理模型未能解释的等效加速度"，从而提高模型的可解释性和跨场景适应能力。

## 物理约束损失函数

项目采用多目标PINN损失，对轨道预报结果和推力序列同时施加约束。主要损失项包括：

- **位置误差损失**：约束预测轨道与参考轨道的一致性；
- **末端误差损失**：提高预报窗口末端位置精度；
- **推力平滑损失**：抑制相邻时刻推力的非物理突变；
- **能量一致性损失**：约束轨道比机械能变化率与推力做功率相匹配；
- **推力幅值正则项**：在多解情况下优先选择较小的等效推力；
- **推力边界损失**：惩罚超出合理推力范围的预测结果。

位置项可使用Huber损失，以减弱异常轨道点和局部数据误差对模型训练的影响。多项损失共同作用，使模型不仅追求较小的位置误差，还需满足推力连续性、能量关系和幅值边界等物理要求。

## 雷达精密定轨与机动融合

项目构建了武汉单站雷达观测仿真场景，观测量包括：

- 斜距；
- 方位角；
- 俯仰角；
- 测站可见性与高度角约束。

在传统轨道确定流程中，根据短弧雷达观测估计航天器初始位置和速度，并分析未知连续推力对定轨结果的影响。进一步将PINN+LSTM输出的机动信息作为动力学先验引入定轨与传播过程，通过沿迹方向施加紧约束、径向和法向施加宽松约束的方式，使定轨算法能够更好地区分初始状态误差和真实机动效应。

该融合方式并不使用人工智能模型替代轨道确定，而是利用机动识别结果补充单站短弧观测中缺失的动力学信息，从而改善非合作航天器在弱机动条件下的轨道恢复能力。

## 数据与验证方案

项目最终验证由四类场景组成。

### 1. 真实精密星历轨道预报

使用QK-1航天器OEM精密星历数据进行轨道建模和预报验证。数据时间分辨率为1分钟，覆盖约8天。该场景主要用于评价高精度物理传播与LSTM推力修正对真实轨道演化的描述能力。物理基线采用NRLMSISE-00+EGM96×20+SRP+III力模型，12小时预报中位误差约1.5 km。

### 2. 已知连续小推力注入实验

在真实QK-1轨道参数基础上注入已知RTN连续小推力，构造可控机动样本。训练使用degree-2自洽仿真（数据生成器与物理模型一致），核心特征为物理传播残差的RTN投影。该场景用于评价：

- 连续小推力事件检测能力；
- 推力方向识别能力；
- 推力幅值回归精度；
- 物理残差特征的有效性；
- 不同推力量级和持续时间下的模型稳定性。

### 3. STK HPOP高精度传播器验证

使用STK Astrogator HPOP v10传播器，基于真实QK-1初始状态生成含推力与无推力双轨迹。注入推力沿速度方向，量级9×10⁻⁵ m/s²，燃段1小时，总仿真时长24小时。该场景作为独立于训练体系的第三方验证，用于检验模型在更高精度传播器生成的数据上的泛化能力。

### 4. 单站雷达精密定轨融合实验

以真实QK-1轨道为基础生成武汉站仿真雷达观测，并注入沿迹连续小推力。当前测试采用3小时观测弧段，距离噪声标准差为50 m，测角噪声标准差为0.02°。该场景用于比较传统定轨方法与加入AI机动先验后的定轨结果。

## 核心实验结果

### 12小时半长轴预报

在高精度物理模型（NRLMSISE-00+EGM20+SRP+III）传播下，当前模型在QK-1真实OEM数据上的12小时半长轴中位误差约 **1.5 km**。模型输出的等效推力主要处于 `1×10⁻⁵～3×10⁻⁵ m/s²` 量级，与物理模型误差水平一致，未检测到超越噪声的推力信号。

结合524天轨道高度演化分析（419 km → 273 km自然衰减），当前观测时段内未发现显著的连续小推力事件，模型给出了与物理事实一致的零推力判断。

### 连续小推力检测

在QK-1轨道基础上注入已知连续小推力后，基于物理传播残差构造的RTN特征能够清晰区分机动和非机动样本：

- 机动检测AUC达到 **1.000**；
- 沿迹方向推力回归的决定系数 `R²` 达到 **0.995**；
- 零误报、零漏检。

独立STK HPOP高精度传播器验证：
- 机动检测AUC达到 **0.998**；
- 沿迹方向推力回归R²达到 **0.884**；
- 分类准确率 **95.2%**，零漏检。

结果表明，物理残差特征能够有效突出低量级持续推力对轨道演化的累积影响。模型不仅在自洽仿真数据上表现优异，在独立的高精度传播器生成数据上同样具备良好的泛化能力。

### 雷达定轨融合

在注入 `5×10⁻⁵ m/s²` 沿迹连续推力的单站雷达仿真场景中，将AI机动先验引入定轨与轨道传播后，位置误差相较传统方法明显改善。

该结果表明，当单站短弧雷达观测难以独立辨识弱连续机动时，利用历史轨道数据学习得到的机动先验可以增强动力学模型，缓解轨道状态与未知推力之间的参数耦合问题。

> 上述机动检测和雷达融合结果来源于已知推力注入实验及STK高精度传播器验证，主要用于检验算法能力，不代表QK-1在对应真实观测时段内发生了同等推力机动。

## 项目特点

### 物理模型与数据模型深度融合

项目不采用纯黑箱轨道外推，而是将高精度轨道动力学作为预测主体，神经网络仅估计未知推力和未建模残差，使输出能够直接对应RTN物理量。

### 物理残差特征

通过减除物理传播基线（r_phys_propagated），将km级轨道信号压缩至m/s级推力等效信号。该特征在预燃段≈0、燃段内线性增长、燃后保持常数，天然适合序列模型学习。

### 连续时间推力表达

神经推力函数可以在任意未来查询时刻输出加速度，不局限于整段预报窗口内的单一常值推力，更适合描述缓慢变化或分阶段工作的低推力系统。

### 兼顾精度与训练效率

系统同时提供端到端可微分RK4传播和快速线性化修正方式，可在物理完整性与大规模训练效率之间灵活选择。当前采用训练端（degree-2自洽）与推理端（高精度物理）解耦的策略，兼顾特征纯净性与预报精度。

### 多层次物理约束

除轨道位置误差外，模型还显式考虑末端精度、推力平滑性、能量一致性、推力幅值和物理边界，降低非物理解和过拟合风险。

### 面向非合作航天器应用

方法不依赖航天器主动提供控制指令、推进系统状态或遥测信息，可基于公开轨道数据、精密星历或地基雷达观测开展轨道分析与机动识别。

## 项目结论

本项目完成了从轨道动力学建模、历史轨道序列分析、连续小推力智能识别到雷达精密定轨融合的完整闭环。高精度物理传播器（NRLMSISE-00+EGM20+SRP+III）建立了12小时预报约1.5 km的物理基线。物理传播残差特征在degree-2自洽仿真中实现了T方向推力回归R²=0.995和机动检测AUC=1.000的完美分类，在独立STK HPOP验证中达到了AUC=0.998和R²=0.884的跨体系泛化结果。真实QK-1数据（524天）上的零推力检测结果与轨道被动衰减的物理事实一致。

最终形成的方法保留了传统轨道动力学的可解释性，同时引入了神经网络对未知机动和模型残差的表达能力，可为非合作航天器轨道监测、弱机动检测、精密定轨和中长期轨道预报提供一种可复现、可扩展的技术方案。
