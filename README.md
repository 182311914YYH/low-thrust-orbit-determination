# low-thrust-orbit-determination

# 非合作航天器连续小推力精密定轨与预报

## 项目简介

本项目为企业项目式实习项目，研究对象为存在连续小推力机动的非合作航天器。

针对连续小推力作用下轨道缓慢变化、机动参数未知以及长期轨道预报误差增大等问题，建立一套完整的软件系统，实现：

- 连续小推力轨道动力学建模
- 单站雷达观测仿真
- 精密轨道确定
- 连续小推力参数估计
- 12 h、24 h轨道预报
- 定轨与预报误差分析
- 模型失配与算法鲁棒性分析

项目采用 MATLAB 开发，并按照模块化的软件工程方式组织代码，为后续分段估计、公开轨道数据验证及智能预测方法扩展预留统一接口。

## 项目统一规范

### 单位

| 物理量 | 单位 |
|------|------|
| 长度 | m |
| 速度 | m/s |
| 加速度 | m/s² |
| 时间 | s |
| 角度 | rad |

### 坐标系

项目统一使用：

- ECI：地心惯性坐标系
- ECEF：地心地固坐标系
- ENU：站心东北天坐标系
- RTN：轨道坐标系

### 软件规范

- 所有公共参数统一保存在 `default_config.m`
- 各模块不得重复定义公共常数
- 各模块通过统一接口交换数据
- 长度、速度、加速度和角度单位保持统一
- 新增功能原则上不得修改已有模块接口
- 所有核心程序均采用 MATLAB 编写

