# low-thrust-orbit-determination

# 非合作航天器连续小推力精密定轨与智能预报

## 项目简介

本项目为企业项目式实习项目，研究对象为存在连续小推力、轨道缓慢演化及潜在非合作机动行为的低轨航天器，并以公开可获取的星链卫星历史轨道数据作为后续真实数据验证来源。

针对连续小推力作用下轨道变化缓慢、机动参数未知、传统动力学模型存在误差以及长期轨道预报精度下降等问题，项目首先建立基于轨道动力学和雷达观测的精密定轨与预报基线系统，在此基础上进一步引入 Informer 与图神经网络 GNN，形成“物理模型驱动、数据模型修正、轨道动力学再积分”的智能轨道预测方法。

项目最终目标是建立一套完整的非合作航天器轨道确定与智能预报系统，实现：

- 连续小推力轨道动力学建模
- 单站雷达观测仿真与观测误差建模
- 精密轨道确定
- 连续小推力及经验加速度参数估计
- 星链公开历史轨道数据读取与样本构建
- 12 h、24 h及更长时间轨道预报
- ECI与RTN坐标系误差分析
- 模型失配、缺测、异常值及初值偏差条件下的鲁棒性分析
- 基于 Informer 的单星时间演化特征提取
- 基于 GNN 的星间空间关联特征提取
- RTN残差加速度预测
- 物理传播器与人工智能模型融合再积分
- 传统物理算法与智能融合算法的对比验证

项目第一阶段采用 MATLAB 完成动力学、观测、定轨、小推力估计、轨道预报和算法鲁棒性分析，已经形成完整的物理算法闭环与对照实验基线。后续阶段将全部核心算法统一迁移至 Python，并在统一数据接口下完成星链数据处理、物理传播、Informer、GNN、残差加速度预测和轨道再积分。

---

## 项目研究目标

本项目不采用纯数据驱动方式直接预测卫星绝对位置，而是采用物理模型与人工智能相结合的混合预测方法。

基础轨道运动由物理传播器计算，Informer和GNN主要学习传统动力学模型难以准确描述的剩余误差，并将其表示为RTN坐标系下的残差加速度：

```text
物理传播器
    +
Informer时间特征
    +
GNN星间空间关系
    ↓
RTN残差加速度
    ↓
轨道动力学再积分
    ↓
修正后的轨道预报结果
```

该方法能够保留轨道动力学的物理可解释性，同时利用星链多卫星、长时间序列数据提高轨道预报精度。

## 核心融合架构

项目后续采用以下统一技术架构：

```text
星链多卫星历史状态序列
        │
        ├───────────────┐
        │               │
        ▼               ▼
物理传播器基线      时间序列特征构建
        │               │
        │               ▼
        │          Informer编码器
        │               │
        │               ▼
        │          单星时间特征
        │               │
        │               ▼
        │          GNN空间关系融合
        │               │
        │               ▼
        │        RTN残差加速度预测
        │               │
        └───────┬───────┘
                ▼
        修正后的总加速度
                │
                ▼
          轨道动力学再积分
                │
                ▼
          最终轨道预报结果
```

融合模型输出不直接采用卫星绝对位置，而是输出：

```text
ΔaR：RTN径向残差加速度
ΔaT：RTN沿迹残差加速度
ΔaN：RTN法向残差加速度
```

总加速度表示为：

```text
a_total = a_physics + C_RTN_to_ECI · Δa_RTN
```

其中：

- `a_physics` 为物理传播器计算的加速度；
- `Δa_RTN` 为Informer-GNN预测的RTN残差加速度；
- `C_RTN_to_ECI` 为RTN到惯性坐标系的方向余弦矩阵。

修正后的总加速度重新进入轨道微分方程进行积分，从而获得满足动力学连续性的轨道预报结果。

## 星链数据集方案

### 数据来源

项目后续真实数据统一采用星链卫星公开历史轨道数据，不引入其他卫星星座作为主要数据集。

主要数据形式包括：

- Space-Track GP数据
- Space-Track GP_History历史数据
- OMM轨道数据
- TLE历史轨道根数
- 星链卫星基本编号、历元和轨道壳层信息

### 数据用途

星链历史数据主要用于：

- 多颗卫星轨道演化规律分析
- 物理传播器基线误差统计
- Informer时间序列样本构建
- GNN星间图结构构建
- RTN状态残差构建
- RTN残差加速度标签构建
- 不同预报时长下的精度验证
- 不同轨道面、不同卫星和不同时间段的泛化测试

### 数据划分原则

为避免未来信息泄漏，数据集不得随机打乱后直接划分。

建议采用以下两类划分方式：

#### 按时间划分

```text
较早时间段：训练集
中间时间段：验证集
较晚时间段：测试集
```

#### 按卫星划分

```text
部分星链卫星：训练集
部分未参与训练的卫星：验证集
完全未参与训练的卫星：测试集
```

最终测试应同时包含：

- 未参与训练的未来时间段
- 未参与训练的星链卫星
- 不同轨道面和不同轨道壳层
- 正常轨道演化与疑似机动时间段

### 数据精度说明

公开TLE或OMM数据属于公开编目轨道数据，不等同于高精度实测轨道真值。因此项目中的真实数据验证主要用于：

- 公开轨道数据一致性验证
- 不同算法相对精度比较
- 轨道预报误差变化趋势分析
- 星链多卫星数据驱动建模验证

项目报告中不得将TLE或OMM直接表述为绝对高精度真值。

## Informer时间特征编码器

Informer负责提取单颗星链卫星在较长历史时间范围内的轨道变化规律。

### 输入特征

单颗卫星的时间序列特征可包括：

- 位置和速度
- 经典轨道根数
- 平均轨道根数
- 半长轴、偏心率、倾角
- 升交点赤经
- 近地点幅角
- 平近点角或纬度幅角
- 物理传播器预测状态
- ECI状态残差
- RTN位置残差
- RTN速度残差
- 估计经验加速度
- 轨道周期
- 历元时间编码
- 数据间隔
- 观测缺失掩码
- 轨道面编号
- 轨道壳层编号

### 输出特征

Informer不直接输出最终轨道位置，而是输出单星时间编码特征：

```text
h_time
```

该特征用于描述：

- 轨道误差随时间的演化规律
- 大气阻力变化趋势
- 沿迹误差积累规律
- 潜在机动前后状态变化
- 长时间依赖关系

## GNN星间空间关系建模

GNN用于描述同一时刻不同星链卫星之间的空间关联和共享环境影响。

### 图节点

每颗星链卫星作为一个图节点。

节点特征包括：

- Informer输出的时间特征
- 当前卫星轨道状态
- 轨道根数
- RTN误差
- 物理模型参数
- 轨道面和轨道壳层信息

### 图边构建

图边可根据以下规则建立：

- 同一轨道面内相邻卫星
- 空间距离最近的若干卫星
- 相似半长轴卫星
- 相似倾角卫星
- 相似轨道周期卫星
- 同一轨道壳层卫星
- 相位差小于设定阈值的卫星

图结构应支持随时间更新的动态图。

### GNN输出

GNN融合多颗卫星的空间关联信息后，输出每颗目标卫星的空间增强特征：

```text
h_space
```

随后由输出层预测：

```text
[ΔaR, ΔaT, ΔaN]
```

## RTN残差加速度标签构建

RTN残差加速度是物理模型与人工智能模型连接的关键变量。

标签构建流程为：

```text
公开星链后续轨道状态
        -
物理传播器预测轨道状态
        ↓
ECI状态残差
        ↓
RTN状态残差
        ↓
平滑与数值微分
        ↓
RTN残差加速度标签
```

标签生成时需要注意：

- 数值微分会放大TLE噪声；
- 应采用平滑、局部多项式拟合或窗口估计；
- 不得直接对原始TLE位置做简单二阶差分；
- 应剔除明显异常TLE和轨道跳变点；
- 疑似真实机动段应单独标记；
- 标签应保留质量标识和置信度权重。

## 模型训练策略

建议按照由简单到复杂的顺序训练。

### 阶段一：物理模型基线

仅运行物理传播器，得到：

- 12 h预报误差
- 24 h预报误差
- RTN分量误差
- 末端位置误差
- 不同卫星误差分布

### 阶段二：Informer单星模型

只使用单颗卫星历史序列，不建立星间图。

验证Informer是否能够改善：

- 沿迹误差
- 24 h末端位置误差
- 长期误差增长速度

### 阶段三：Informer-GNN模型

加入多颗星链卫星图结构，验证星间空间信息是否进一步提高预测精度。

### 阶段四：物理融合再积分

将网络预测的RTN残差加速度加入物理传播器，再进行轨道积分。

### 阶段五：联合训练

在条件允许时，使轨道再积分过程具备可微分能力，使用最终轨道误差反向优化Informer-GNN模型。

## 损失函数

模型训练可采用多目标损失函数：

```text
L_total =
    λ1 L_acc
  + λ2 L_state
  + λ3 L_RTN
  + λ4 L_endpoint
  + λ5 L_smooth
  + λ6 L_physics
```

其中：

- `L_acc`：RTN残差加速度误差；
- `L_state`：再积分后的状态误差；
- `L_RTN`：RTN位置和速度误差；
- `L_endpoint`：预报终点误差；
- `L_smooth`：残差加速度时间平滑约束；
- `L_physics`：加速度幅值、连续性和物理边界约束。

损失函数应重点提高沿迹方向预测精度，同时防止网络输出不合理的大幅加速度。
