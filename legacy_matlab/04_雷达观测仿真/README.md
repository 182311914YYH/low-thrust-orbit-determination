
enu_obs_model.m 【04_雷达观测仿真】
作用：雷达观测核心函数
输入：cfg、时间序列、N×6 ECI 轨道状态（来自 orbit_propagate 输出）
功能：
① ECI 转 ECEF，卫星与武汉站做站心 ENU 转换；
② 计算斜距、方位角、俯仰角理论值；
③ 判断卫星是否满足最低俯仰角可见条件；
④ 根据 cfg 噪声配置叠加高斯噪声；
输出：N×3 观测矩阵、N×1 可见标记数组（1 可见 / 0 不可见）
test_radar_scene.m 【11_测试程序】
作用：单元测试脚本，自动加载配置、读取成员 1 输出的真值轨道，执行三组场景测试；自动添加 02 配置文件夹路径，全程读取 cfg 参数；运行输出各场景观测结果、可见弧段统计。
