文件 1：dyn_equation.m
存放位置：03_轨道动力学\dyn_equation.m
作用：轨道微分方程右端函数，输入时间 t、6 维 ECI 状态、配置 cfg，输出加速度，集成中心引力、J2 摄动、沿迹常值小推力模型；完全从 cfg 读取开关与参数，无硬编码。
核心逻辑：根据 cfg.model.truth 内开关判断是否叠加 J2、推力加速度；RTN 轨道坐标系推力转换到 ECI 坐标系叠加。

建模工作全部写在 dyn_equation.m 里：
建立中心引力（二体）动力学模型；
建立 J2 地球扁率摄动加速度模型；
建立 RTN 沿迹连续小推力模型，并完成轨道系→ECI 惯性系坐标转换；
将所有力叠加，组装成轨道六维状态微分方程，这就是完整动力学数学模型。

文件 2：orbit_propagate.m
存放位置：03_轨道动力学\orbit_propagate.m
作用：轨道数值传播封装接口，对外标准输入输出，供雷达模块直接调用。
输入：cfg、初始 6 维 ECI 状态 x0、仿真总时长；
输出：时间数组t(N×1)、轨道真值状态矩阵state(N×6)，严格遵循项目接口规范 [x,y,z,vx,vy,vz]。
核心逻辑：调用 ode113 积分 dyn_equation，积分步长、容差、积分器全部取自 cfg，自动生成均匀时间序列。

文件 3：test_dyn_switch.m（单元测试脚本）
存放位置：11_测试程序\test_dyn_switch.m
作用：首日测试脚本，完成三项开关验证，打印 / 保存测试结果，用于交付验收：
纯二体模型（关闭 J2、关闭推力）传播测试；
二体 + J2 模型（开启 J2、关闭推力）传播测试；
二体 + J2 + 沿迹小推力（全部开启）完整真值传播测试；
附加功能：自动添加02_参数配置路径加载 cfg，输出各场景轨道周期、末端位置速度对比，保存测试数据用于下午联调。

文件依赖关系
test_dyn_switch.m → 调用 orbit_propagate.m → 调用 dyn_equation.m
所有公共常数、仿真边界、模型开关统一读取 02_参数配置/default_config.m，无任何硬编码数值。

首日任务 1 分步执行流程
步骤 1：编写 dyn_equation.m（底层动力学）
函数入参包含 cfg，所有 mu、Re、J2、推力加速度、模型开关全部从 cfg 提取；
实现位置求中心引力加速度；
实现 J2 摄动加速度计算，由 cfg.useJ2 控制是否叠加；
实现 RTN→ECI 坐标转换，将沿迹推力加速度叠加到状态导数；
返回 dxdt = [vx,vy,vz,ax,ay,az]'。

步骤 2：编写 orbit_propagate.m（标准化传播接口）
自动读取 cfg 内积分器、absTol、relTol、integrationStep；
生成从 0 到 cfg.sim.truthDuration 的均匀时间节点；
调用 ode113 求解微分方程 dyn_equation；
格式化输出 t (N×1)、state (N×6)，匹配下游雷达模块输入标准。

步骤 3：编写单元测试脚本 test_dyn_switch.m
脚本开头自动添加02_参数配置搜索路径，加载 cfg；
分三组场景修改 cfg 内模型开关，依次调用 orbit_propagate；
场景 1：仅中心引力（二体）
场景 2：中心引力 + J2，推力关闭
场景 3：中心引力 + J2 + 沿迹小推力全部开启
每组传播完成后输出：轨道末端状态、轨道周期、最大位置变化；
保存场景 3 完整真值轨道t、state到09_数据与实验结果，供下午联合调试时成员 2 雷达模块读取。

步骤 4：自检规范（强制检查项）
打开全部 3 个文件，检索无写死数字（3.986e14、550e3、J2 数值、步长等）；
所有物理参数、开关、积分设置全部通过 cfg.xxx 读取；
输出t(N×1)、state(N×6)严格匹配 cfg.interface 定义的数据维度与顺序。
